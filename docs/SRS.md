# Student Hub SRS
Student Hub is a multi-tenant student success SaaS with Student, Moderator, and Admin roles. Functional scope includes account lifecycle, communities, resources, notes, doubts, comments, votes, bookmarks, notifications, chats, messages, study groups, coding contests, achievements, placement content, reports, and audit trails. Non-functional requirements: secure JWT/refresh sessions, OWASP controls, RBAC, pagination, indexes, soft deletes, observability, Dockerized local development, CI/CD, and cloud deployment on Vercel, Render/Railway, MongoDB Atlas, Redis, and Cloudinary.
